과목명: 데이터베이스 설계
교수명: 김영수
수업목표: 관계형 데이터베이스 설계 원리와 SQL 활용 능력을 습득한다.
수업방식: 강의 + 실습
평가방법: 중간고사 30%, 기말고사 30%, 프로젝트 30%, 출석 10%
주차별 강의계획:
1주차 - 데이터베이스 개요 및 필요성
2주차 - ER 모델링 이론과 실습
3주차 - 관계형 모델과 제약조건
4주차 - SQL 기초 문법
5주차 - 데이터 정의어(DDL)
6주차 - 데이터 조작어(DML)
7주차 - 데이터 제어어(DCL)
8주차 - 중간고사
9~12주차 - 고급 SQL 및 최적화
13주차 - 트랜잭션 관리
14주차 - 프로젝트 중간발표
15주차 - 기말 프로젝트 발표 및 평가
